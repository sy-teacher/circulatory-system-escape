# 순환계 방탈출: 수연쌤의 혈관 탐험

중학교 2학년 **[9과13-02] 순환계의 구조와 기능을 이해하고, 혈액의 순환 경로를 종합하여 발표할 수 있다.** 를 위한 20분 분량의 3D 교육 게임입니다.

학생은 놀이공원(수학여행)에서 회전 열차를 타다가 혈액 속 탐사선에서 깨어나, 옆자리의 수연쌤과 함께
**관찰 → 단서 연결 → 위치·경로 추론 → 지도 완성 → 개인별 보충 학습** 을 경험합니다.

- 백엔드·로그인·API 키·생성형 AI 실시간 호출 없이 브라우저에서 실행됩니다.
- 모든 모델·소리는 코드로 생성합니다(외부 에셋 없음, 오프라인 실행 가능).
- 학생 이름을 묻지 않으며, 기록은 그 기기의 브라우저(localStorage)에만 저장됩니다.

## 1. 설치 · 실행 · 빌드

Node.js 20 이상(개발 시 v24.11.0, npm 11.6.1 사용)이 필요합니다.

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 터미널에 표시된 주소(기본 `http://localhost:5173`)를 엽니다.

```bash
npm run build
```

`dist/` 폴더가 만들어집니다. 상대 경로로 빌드되므로 학교 웹 서버의 아무 폴더에 올려도 됩니다.
빌드 결과를 내 컴퓨터에서 확인하려면:

```bash
npm run preview
```

자동 검증(게임 규칙·기록 보존·결과 생성·데이터 정확성):

```bash
npm test
```

타입 검사만:

```bash
npm run typecheck
```

> `dist/index.html`을 파일로 직접 더블클릭해 열면(파일 프로토콜) 브라우저 보안 정책 때문에 실행되지 않을 수 있습니다.
> `npm run preview` 또는 학교 웹 서버를 이용하세요.

## 3. 교사가 수정할 위치

| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| **오답 허용 횟수**(기본 3번, 4번째 오답이면 출발점으로), 최소 단서 수, 이동 시간, 설명 활동 시간 | `src/data/config.ts` |
| **핵심 10문항·복습 6문항**(문제, 선택지, 정답, 근거, 힌트, 해설, 오답별 피드백, 오답별 보충 개념) | `src/data/questions.ts` |
| 각 구역의 **관찰 단서 문장**, 도착 대사, 이동 중 안내 문구, 정차 위치 | `src/data/route.ts` |
| **도입·귀환·탈출 대사**, 탈출 메시지, 30초 설명 활동 문장 | `src/data/dialogue.ts` |
| **보충 개념** 설명, ‘다시 생각하기’ 질문, 마지막 O/X 재확인 문장 | `src/data/concepts.ts` |
| 지도 지점 이름·배치·산소 기호 | `src/data/map.ts` |
| 심장 방 연결·판막·벽 두께 비교값 | `src/data/heart.ts` |

수정 요령

- 선택지는 **id로 채점**합니다. 화면에서는 순서를 섞어 보여 주므로 보기 순서를 바꿔도 기록이 어긋나지 않습니다.
  `correctAnswer`/`correctReason`에는 선택지의 `id`를 적습니다.
- 오답 선택지를 추가하면 `misconceptionFeedback`(그 오답에 대한 설명)과 `misconceptionConcepts`(보충 개념 id)도 함께 적어 주세요.
  `npm test`가 빠진 항목을 알려 줍니다.
- 단서·도착 대사·힌트에는 **그 구역의 정답 장소 이름을 쓰지 않습니다**(`answerTerms`). `npm test`가 자동으로 검사합니다.
- 학생 대상 표현은 ‘산소가 적은 혈액’, ‘산소가 풍부한 혈액’으로 통일합니다(‘정맥혈’, ‘동맥혈’은 검사에서 걸립니다).

## 4. 게임 흐름

```
시작 화면 → 도입(놀이공원 → 탐사선에서 깨어남)
→ [도착 → 관찰(단서 2개 이상) → 위치·근거 선택 → 설명 → 지도 갱신 → 이동] × 16
   핵심: 좌심실 → (대동맥) → 온몸의 모세혈관 → 대정맥 → 우심방 → 우심실 → 폐동맥 → 폐의 모세혈관 → 폐정맥 → 좌심방 → 좌심실
   복습(보너스, 오답 수에 영향 없음): 적혈구 · 세포호흡 · 혈소판 · 혈관 구조 · 혈장 · 백혈구
→ 좌심실 귀환 → 허파순환·온몸순환 범위 고르기 → 헷갈린 개념 O/X 재확인 → 놀이공원으로 탈출(완성된 지도) → 학습 진단 보고서 → 30초 설명 활동
```

오답 규칙

- 위치와 근거를 함께 제출하며, 둘 중 하나라도 틀리면 오답 1회입니다(위치만 맞은 경우는 결과에 따로 표시).
- 현재 탐험의 오답 1~3번째: 오답에 맞춘 설명과 추가 단서를 보고 같은 자리에서 다시 추론합니다.
- 4번째 오답: 좌심실 출발점으로 돌아갑니다. **현재 탐험의 오답 수만 0이 되고**, 최초 응답·전체 응답 이력·힌트 기록·보충 개념은 그대로 남습니다.
- 재시작 후 이미 해결한 구역은 ‘기억한 구역’으로 짧게 지나가고, 틀렸거나 아직 풀지 않은 문제는 다시 나옵니다.
- 힌트·복습 문제·중복 클릭은 오답 수를 늘리지 않습니다.
- 언제든 ‘지금까지 결과 보기’로 중간 기록(‘탐험 중간 기록’)을 볼 수 있습니다.

## 5. 폴더 구조

```
src/
  data/      콘텐츠(문항·단서·대사·개념·지도·심장 구조·교사용 설정)
  state/     게임 규칙(순수 함수 상태 머신), 선택자, 저장소, Zustand 스토어, 이벤트
  report/    학습 진단 보고서 생성, 복사용 텍스트
  scene/     3D: 공간(locations), 탐사선(vehicle), 수연쌤(character), 카메라, 이동, 공용 모듈(shared)
  ui/        HUD, 대화창, 단서, 퀴즈, 피드백, 지도, 결과, 시작 화면, 설정, 간소화 모드
  audio/     Web Audio API로 합성한 효과음과 심장박동
  tests/     자동 검증(vitest)
```

자동 검증이 확인하는 대표 항목: 1~3번째 오답 진행과 4번째 귀환, 귀환 후 최초 응답·전체 이력 보존, 힌트·복습·중복 제출이 오답 수를 늘리지 않음,
id 기반 채점(보기 순서 무관), 위치만 맞은 경우의 구분 기록, 이어하기 복원, 손상된 저장 데이터 무시, 저장소가 없을 때도 진행,
순환 경로·지도 연결·판막 연결의 일치, 단서·힌트·대사·HUD·지도·중간 보고서에 미해결 정답 이름이 나오지 않음,
'정맥혈'·'동맥혈'·'파란 혈액'·'산소 0' 같은 금지 표현 없음.

### 제한 사항

- 실제 학교 기기(크롬북·저사양 노트북·태블릿)의 GPU에서 프레임 속도를 측정하지는 못했습니다. 느리면 설정의 **저사양 모드**를 켜 주세요(해상도·혈구 수·재질 단순화).
- 화면 캡처 검증은 소프트웨어 렌더러(SwiftShader)로 했습니다. 실제 GPU에서는 색·밝기가 약간 다를 수 있습니다.
- 효과음은 코드로 합성하며, 자동 검증에서는 소리가 실제로 들리는지까지는 확인할 수 없었습니다(재생 호출과 음소거 상태만 확인).
- 휴대폰 세로 화면에서는 3D 화면이 작아집니다. 수업에서는 노트북·태블릿 가로 화면을 권장합니다.
- '결과 텍스트 복사'는 브라우저의 클립보드 권한 정책에 따라 자동 복사가 막히면 선택 가능한 글상자로 대신 보여 줍니다.
- 진행 중 결과 보고서에서는 아직 풀지 않은 단계의 장소 이름이 들어 있는 개념 설명을 숨기고, 탈출 후 모두 보여 줍니다.
- 브라우저 저장소를 지우거나 다른 기기·브라우저로 옮기면 기록이 이어지지 않습니다(서버에 저장하지 않기 때문).
- 첨부된 캐릭터 시트(수연쌤)를 바탕으로 3D 모델과 대화창 초상화를 직접 만들었습니다. 원본 이미지 파일을 그대로 쓰지 않았습니다.
